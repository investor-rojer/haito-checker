# 高配当株 買い時チェッカー

日本株の銘柄コードを入力すると、株価チャート・配当推移・利回りバンド・買い時スコアを表示する Streamlit アプリ。

## 使い方（ローカル）

```bash
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで銘柄コード（例: `8306`）を入力。

## 買い時スコアの内訳

| 項目 | 重み |
|---|---|
| 利回りの割安度（過去5年レンジ内の位置） | 35% |
| 株主還元（連続増配・非減配年数） | 15% |
| PERの低さ | 18% |
| PBRの低さ | 12% |
| 増配傾向（平均増配率） | 10% |
| 株価位置（52週レンジの押し目度） | 10% |

## データ源

- 株価: yfinance
- PER（会社予想）・PBR・業種: 株探（kabutan.jp）
- 配当: IRバンク（irbank.net）

※投資判断は自己責任で。利回りバンドは概算（暦年ベース）です。
